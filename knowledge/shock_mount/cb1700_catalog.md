# CB1700 Series Catalog

**Chunk:** `shock_mount/cb1700_catalog`
**Source:** `helical.pdf`, PDF page 6 (printed page 16), for Shock Average K,
Vibration Average K, and rated dynamic travel. `Helical_English.pdf`, PDF page
36 (printed page 43), supplies Max Static F. Values are cross-checked against
`catalog.py` (`CB1700_CATALOG`).
**Grounding:** catalogue-verified against the supplied legacy Helical/Aeroflex
and Socitec catalogues. Obtain a current vendor revision before procurement.

CB1700 is a standard-construction Helical wire-rope isolator on 7/8 inch wire
rope. It is the heaviest supported series and is included in automatic
selection. It replaces the obsolete CB1800 reference in the project documents.
