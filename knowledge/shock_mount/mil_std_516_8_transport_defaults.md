# MIL-STD-810H Method 516.8: Transportation Default Criteria Limits

**Source:** MIL-STD-810H, Method 516.8, method pages 516.8-26 to 516.8-27,
Procedure II transportation shock guidance. This summary is based on the
project copy of `MIL-STD-810H.pdf`.

## What the default criteria are for

Procedure II provides default transportation-shock criteria for use when field
data is unavailable. The method describes these as representative of certain
wheeled ground-vehicle transportation conditions, not as a unique requirement
for every vehicle, route, item, or mounting arrangement.

## Tailoring remains necessary

Where field measurements or an approved requirement exist, they should be
used to tailor the shock exposure. The procedure also notes that transportation
shock must be considered together with the relevant transportation vibration
environment where applicable.

## Project interpretation

Do not infer a project input pulse solely from a generic transportation table.
Record whether `input_g`, `to_ms`, and pulse shape came from a customer
requirement, vehicle data, a test plan, or a documented conservative design
assumption.

## Use in answers

Use this source to explain the limitation of generic defaults and why the
application should report its assumed shock environment clearly.
