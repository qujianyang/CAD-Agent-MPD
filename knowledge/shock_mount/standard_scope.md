# Standard Scope

**Chunk:** `shock_mount/standard_scope`
**Grounding:** the standard-method scope is source-backed; project applicability
must be approved through the project or customer requirement.
**Source:** MIL-STD-810H Method 516.8, method pages 516.8-1 to 516.8-2,
516.8-4, and 516.8-26 to 516.8-27. See the focused
`mil_std_516_8_*.md` source pages.

## This tool is not a qualification test

A PASS from this application is an engineering selection result. It does not
prove that a rack has passed a physical MIL-STD qualification test. Physical
qualification requires the applicable tailored procedure, documented setup,
instrumentation, exposures, and acceptance process.

## What the standard supports

MIL-STD-810H Method 516.8 is the shock-method reference for mechanically
induced shock. It requires the procedure, pulse, level, duration, directions,
and number of shocks to be tailored to the item and its life-cycle environment.
Procedure I addresses functional shock; Procedure II addresses transportation
shock.

## Project boundary

The application performs engineering selection and verification calculations
using a validated SDOF velocity-impulse model. It does not perform or certify a
physical MIL-STD qualification test. Method 514.8 vibration is a separate
environmental analysis and is not part of the shock-isolator calculation.

## Requirement still needed

The project/customer requirement must confirm which tailored Method 516.8
condition applies to the actual installation and must state the protected
equipment's transmitted-acceleration acceptance limit.
