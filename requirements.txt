# CAD Agent — Shock Mount Selection
# Pinned to versions verified to work end-to-end on Windows + NVIDIA API.
#
# Install:
#   pip install -r requirements.txt
#
# Activate venv (Windows PowerShell):
#   .\mpd\Scripts\Activate.ps1
#
# Run app:
#   streamlit run app.py
#   # or, LAN-accessible:
#   streamlit run app.py --server.port 8501 --server.address 0.0.0.0
#
# Notes:
#   - pywin32 is only needed if you run the SolidWorks COM extraction
#     (test_assembly.py / cad_compliance_checker.py). On a Linux server
#     that won't talk to SolidWorks, you can omit it.
#   - sentence-transformers is a fallback for setup_knowledge.py --local;
#     skip it if you only use the NVIDIA API for embeddings.
#   - pymupdf / pymupdf4llm are only needed by setup_rag.py (the legacy
#     MIL-STD PDF ingestion). The new hierarchical knowledge base
#     (setup_knowledge.py) doesn't need them.
